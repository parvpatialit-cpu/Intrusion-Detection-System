# Intrusion Detection System

## Project Overview
This project focuses on detecting network intrusions using machine learning classification techniques. The goal is to classify network activity as normal or attack.

## Dataset
- **Dataset:** CIDS 2017
- **Learning Type:** Supervised Learning
- **Task:** Classification
- **Classes:** Normal and Attack

## Technologies Used
- Python
- Machine Learning
- Google Colab
- Jupyter Notebook

## Project Implementation
The project uses machine learning algorithms to classify network traffic. Model evaluation is performed using 10-fold cross-validation.

## Project Notebook
The complete implementation and analysis are available in the Jupyter Notebook uploaded to this repository.

## How to Run
1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Download the dataset from its original source and update the dataset path in the notebook if required.
4. Run the notebook cells in order.
